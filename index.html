常見問題

買之前先看這裡

我自己叫 Claude Code 做不就好了，為什麼要買？

你可以試試看，但空手上陣會撞到我們實測抓出來的那些坑——像是部署權限只能手動設定、日期時間會被試算表自動轉換位移 8 小時這種連 Google 官方工具都會出的雷。這個起始包已經把這些問題排除掉、寫進設定裡，你買的不是一句提示詞，是三輪真實部署驗證過的成果，省下自己一個一個踩雷的時間。

我完全不會寫程式，真的做得出來嗎？

可以。你要做的是把店家資料講清楚（店名、服務項目、價格這些），實際生成程式碼、建立試算表、部署上線，全部是 Claude Code 在做。整套流程裡沒有一步需要你自己寫或改程式碼。

要另外付 Claude Code 的錢嗎？

要。這堂課教你怎麼用 Claude Code 做出這套系統，但 Claude Code 本身的使用權限（Anthropic 帳號）需要你自己另外準備，不包含在課程費用裡。

中途卡住、跳出錯誤訊息怎麼辦？

除了三個 Google 規定一定要本人操作的關卡，其餘任何錯誤都可以直接把畫面截圖給 Claude Code，跟它說「這裡跳出這個」，它會自己排查、自己修正，不需要你自己懂錯誤訊息在說什麼。

之後想改內容（改價格、加服務項目）要另外收費嗎？

不用。這是你自己的系統，之後想怎麼改都直接跟 Claude Code 講一句話就好，跟做第一版時是同一套方式，不需要再回來找我或另外付費。

後台資料安全嗎？會不會被別人看到？

後台就是一份你自己 Google 帳號底下的試算表，除非你自己按分享，不會有第二個人看得到，也沒有另外的登入帳號密碼系統需要你管理。

我不是美業，是其他也需要預約的行業，能用嗎？

這套系統設計給任何「需要排時段」的服務型生意，教材以美業（美甲、美睫等）為範例，但客製化的方式同樣適用其他行業，跟 Claude Code 講清楚你的行業別跟服務項目即可。
